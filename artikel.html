Memahami Konsep Dasar HTML

Berfungsi sebagai kerangka atau fondasi utama dari sebuah halaman web agar dapat dibaca oleh web browser.Mengatur tata letak dan struktur informasi seperti teks, gambar, video, hingga tautan (link) di dalam website.Bukan merupakan bahasa pemrograman, melainkan bahasa markup yang menggunakan tanda penanda (tag)

Memahami konsep dasar css

CSS (Cascading Style Sheets) adalah bahasa yang digunakan untuk mengatur tampilan, warna, ukuran, dan posisi elemen HTML pada halaman website.Jika HTML bertindak sebagai kerangka atau struktur konten (seperti teks dan gambar), maka CSS berfungsi sebagai desain dan penata gaya agar halaman web terlihat menarik.
